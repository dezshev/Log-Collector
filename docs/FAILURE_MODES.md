# Инварианты и поведение при отказах

Проверяемые отказы, наблюдаемое поведение и ограничения реализации. Сценарии относятся к локальной среде испытаний.

## Инварианты

1. Кадр имеет ровно одно допустимое значение типа, ограниченную длину и полностью проверенное тело; чтение не зависит от размера TCP-пакета.
2. Источник записи совпадает с источником соединения. Роль администратора нельзя получить командой внутри агентской сессии.
3. Корректная принятая запись даёт ровно один результат: STORED, FILTERED или FAILED. По каждому уровню RECEIVED = STORED + FILTERED + FAILED.
4. STORED и увеличение соответствующего счётчика допустимы только после записи и Flush. Ошибка записи никогда не возвращается как успех.
5. SetFilter и обработка Log упорядочены одной блокировкой; правила одного источника не меняют правила другого.
6. В файле одна физическая строка означает одну целую запись. Переносы, табуляция, обратная косая черта и управляющие символы сообщения экранируются.
7. Одновременно открыт один активный файл. Ротация не режет запись; после перезапуска целые ранее записанные строки не обнуляются.
8. Каждый сеанс удаляет только своё подключение. Одинаковое имя у нескольких соединений не теряет информацию о других.
9. Начатое сообщение имеет общий срок чтения. Количество подключений и настроенных источников ограничено.
10. После остановки сервер закрывает сокеты, ждёт потоки и только затем освобождает журнал.

## Матрица отказов

| Случай | Ожидаемая реакция | Доказательство / состояние |
| --- | --- | --- |
| Кадр доставлен по одному байту | Собрать полностью, не путать границы | Автотест фрагментации |
| Несколько кадров склеены | Читать последовательно | Автотест двух кадров в одном потоке |
| Обрыв внутри заголовка или тела | Ошибка, без лог-записи | Автотест усечённых кадров |
| Неизвестный тип, неверная длина, лишние байты | Отклонить и закрыть только клиента | Автотесты кодека и некорректного TCP-клиента |
| Неверный UTF-8 / уровень / источник / размер сообщения | Отказ валидации | Автотест модели и кодека |
| Сообщение содержит разделители / переносы / NUL | Сохранить одной физической строкой без потери смысла | Автотест round trip и экранирования |
| Агент присылает чужое имя источника | Отклонить, не записывать | Автотест подмены источника |
| Агент отправляет административную команду | Отклонить команду | Автотест ролей |
| Неправильный административный токен | Отказ приветствия | Автотест авторизации роли |
| Агент простаивает | Не мешает другим; остаётся в пуле | Автотест незавершённого приветствия и shutdown |
| Агент начинает кадр и не заканчивает | Общий таймаут кадра, освобождение соединения | Реальный TCP-тест с таймаутом 200 мс |
| Медленная пофрагментная отправка | Общий срок, не продление на каждый Read | Реальный TCP-тест передачи одного байта каждые 40 мс при общем сроке 250 мс |
| Лимит подключений исчерпан | Закрыть избыточного клиента, сохранить существующих | Автотест лимита |
| Два соединения имеют одинаковое имя | Учитывать оба, закрытие одного оставляет другое | Автотест пула |
| Аварийный обрыв TCP | Удалить соответствующий сеанс | Автотест RST через LingerOption |
| Несколько потоков пишут одновременно | Целые уникальные записи, точные счётчики | 3 агента, 150 уникальных записей; дополнительно 600 записей при 100 изменениях фильтра |
| Фильтр меняется на активном соединении | Применить к следующим обработанным записям | Тест всех пяти порогов без переподключения |
| Достигнут лимит файла | Новый сегмент перед следующей записью | Автотест уменьшенного лимита |
| Одна запись больше тестового лимита | Сохранить целиком, следующая запись в новом сегменте | Автотест большой записи |
| Перезапуск | Дописать журнал, не потерять завершённые строки | Автотест повторного открытия |
| После аварии остался незавершённый хвост | Удалить только хвост до последней новой строки | Автотест хвоста 5010 байт, проходящего границу блока 4096 |
| Новый сегмент нельзя создать | FAILED, ошибка клиенту, хранение заблокировано до исправления / рестарта | Инъекция отказа: каталог вместо следующего файла; проверка отсутствия ложного STORED |
| Частичная ошибка текущей записи | Перевести writer в отказ; не дописывать к возможному обрывку | Единая ветка отказа; физическое заполнение диска пока не воспроизводилось |
| Ошибка записи и последующая отправка | Повторно FAILED без попытки продолжить повреждённый файл | Автотест двух отказов и согласованности счётчиков |
| Сервер недоступен | Исключение библиотеки, не ложный успех | Автотест недоступного порта |
| Сервер останавливается с активными клиентами | Закрыть сокеты и дождаться потоков | Автотест shutdown и повторного Dispose |
| Ответ потерялся после записи | Исход последней операции неизвестен; не делать скрытый повтор | Тестовый TCP-партнёр записывает лог и закрывается до STORED; в файле одна запись, библиотека сообщает ошибку без повтора |
| Обрыв питания после Flush | Возможна потеря ОС-буферов; физическая сохранность не обещается | Явное ограничение первого варианта |
| Перезапуск после настроенных фильтров | DEBUG по умолчанию, нулевые счётчики; история файлов сохранена | Реальный перезапуск LogServer в тесте подтверждён; долговременное сохранение фильтров пока не реализовано |
| Предел настроенных источников | Новое правило отклоняется, существующие обновляются | Тест 256 правил, отказ 257-го, успешное изменение существующего |
| Не отправлено приветствие | Сеанс закрывается по таймауту | TCP-тест 200 мс и последующего здорового клиента |
| Пустое / ровно максимальное сообщение | Корректная сериализация и сохранение | Кодек и TCP-тест 0 и 65536 байт UTF-8 |
| Точное равенство размеру ротации / пустой сегмент | Не терять запись и корректно выбрать сегмент | Граничный тест файла ровно лимит и пустого последнего файла |
| Неверное подтверждение фильтра | Отклонить ответ и закрыть канал | TCP-партнёр отвечает STORED вместо UPDATED; следующий запрос получает ObjectDisposedException |
| Некорректный снимок | Не показывать значения как действительные | Тесты заголовков, порядка, чисел, дубликатов, тождества и переполнения; проверка в UI |
| Потеря связи GUI / зависший сервер | Окно не блокируется, ошибка отображается, данные очищаются | UI-тесты медленного ответа, потери сервера и повторного подключения |
| Отключение во время запроса | Закрыть сокет без ожидания блокировки Exchange | Тесты библиотеки и окна: быстрее 1 секунды, без ожидания таймаута 5 секунд |
| Поздний ответ после отмены | Не восстановить отменённое соединение / статистику | UI-тесты поколения соединения при отмене и отключении на Refresh |
| Закрытие окна во время ожидания | Закрыть сразу, не обращаться к уничтоженным контролам | UI-тест закрытия при заблокированном начальном снимке |
| Задержано завершение UI-обработки | Не запустить пересекающийся запрос таймера | operationPending до UI-обработки результата; тест автообновления |

## Подтверждено дополнительно

Частичный отказ уже открытого файла: тестовый FileStream записывает половину строки и выбрасывает IOException. Проверены FAILED, запрет дописывания и сохранение целой предыдущей строки при восстановлении после перезапуска.

180-секундная непрерывная нагрузка 8 агентов с 177 изменениями фильтра и 52 сегментами подтверждена точным соответствием подтверждений, уровней и 55620 физических строк ([протокол нагрузки](testing/load/LOAD_REPORT.md)).

## Границы испытаний

Ручная приёмка, клавиатура, целевой DPI, запуск на другом компьютере и двухмашинный обмен отмечены как выполненные по подтверждению владельца проекта.

- Физический отказ накопителя и потеря питания не воспроизводились; частичный отказ записи и перезапуск проверены программной инъекцией.
- Локальный нагрузочный прогон не определяет предельную производительность и последствия любых длительных задержек в реальной сети.
- В одном прогоне сценария медленной передачи клиент получил сброс TCP вместо ожидаемого кадра Error. Повторные полные прогоны успешны; стабильность ожиданий теста требует разбора.
