# Изменения LogCollector

## 05.10.2026

Реализованы модель записи, бинарный TCP-протокол, клиентская библиотека, многопоточный сервер, общий журнал с ротацией и консоль управления. Добавлены проверки кадров, ролей, фильтров, параллельной обработки, отказов записи и восстановления. Выполнен локальный нагрузочный опыт восьми агентов.

## 11.10.2026

Интерфейс администратора переведён на WPF. Добавлены XAML, общие стили, карточки счётчиков, таблицы источников и уровней, история действий. Сохранены фоновый TCP-обмен, отмена, поколения соединения и проверка снимка. Обновлены автоматические проверки окна и снимки интерфейса.

## 12.10.2026

Расширены README и ROADMAP: схемы взаимодействия, галерея WPF, таблицы компонентов, запуск и критерии завершения. Ручная приёмка отмечена выполненной по подтверждению владельца проекта. Нестабильный исход теста медленной передачи отражён в оставшихся технических задачах.
